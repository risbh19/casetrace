# Keep external actions outside the training workflow

An IO can draft and a separate supervisor can approve. The final state records a simulated send within the same database transaction as its audit event.

This supports a complete review demo without creating a bank, telecom or messaging integration. The transaction graph and deadlines stay review aids. Legal answers use citations from the verified section catalog.

The baseline runs without model downloads. Optional inference and embeddings connect only to an approved loopback or internal Compose Ollama address.
